### 🛠️ 目前正在執行的任務 (Current System Status)

我是一名專注於**「流程優化與自動化架構」**的開發者。我熱衷於將重複的人工作業轉化為高效的代碼邏輯，並在複雜的系統中尋找最優的品質解決方案。

* **⚡ 核心成就**：曾實作資料清洗與驗證腳本，成功將**跨日的繁瑣作業壓縮至 45 分鐘內**自動執行完畢。
* **🧩 實戰領域**：具備**電商平台、醫療預約系統及餐飲線上平台**的深度自動化與 QA 經驗。
* **🧪 測試哲學**：比起傳統的手動點擊，我更傾向於使用 **Pytest / Playwright** 建立模組化且可持續維護的測試框架。
